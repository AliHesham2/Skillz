# Stitch Skills

Contains 15 skills: 12 adapted Google Labs Stitch skills and the custom Stitch Studio, Stitch Site Builder, and Stitch Motion skills.

Copy the 15 folders inside this collection's skills/ directory into your Codex skills directory (normally ~/.codex/skills/). Back up existing folders before replacement.

Stitch account access must be configured separately. This collection contains no MCP configuration or API keys. Resolve machine-specific example paths against the installed skill directory. Python is needed for included helpers.

Licenses and provenance notes remain inside each skill. Reviewed sources and revisions are recorded in manifest.json.

UI UX Pro Max is packaged separately in ../ui-ux-pro-max/.
