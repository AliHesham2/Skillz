# Components Library

Reusable component source saved separately from the skill collections.

- [Tilted Grid Hero](tilted-grid-hero/README.md): curved animated image band, original integration prompt, and extracted React component and demo.

- [Wildlife Slider](wildlife-slider/README.md): photographic carousel with expanding previews, responsive copy and thumbnails, optional autoplay and accessible controls.
